# From LLMs to AI Agents — 25 Papers

## Reasoning
CoT (Wei 2022): Reasoning steps improve problem-solving.
ToT (Yao 2023): Branching search over reasoning paths.

## Tool Use
Toolformer (Schick 2023): Self-supervised tool learning.
Gorilla: Fine-tuned for API call generation.

## Agents
ReAct (Yao 2022): Synergistic reasoning and acting.
AutoGPT: Autonomous task decomposition.
MetaGPT: Multi-agent software company simulation.
CrewAI: Role-based agent team orchestration.

## Multi-Agent
ChatDev, AutoGen, AgentVerse — multi-agent conversation frameworks improving on single-agent by 20-40%.

## Safety
Constitutional AI, RLHF, InstructGPT — alignment foundations.

## Key Insight
Tool-use reliability is the primary bottleneck. Current agents fail on 15-30% of API calls.
