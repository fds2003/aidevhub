# Midjourney AI Art — Complete Guide

Midjourney generates production-quality images through Discord. This guide covers setup through commercial delivery.

## Parameters

--ar 16:9 controls aspect ratio. --v 6 selects model version. --s 250 sets stylization. --iw 2 sets image prompt weight.

## Prompt Structure

[subject] + [medium] + [environment] + [lighting] + [color] + [mood]

Multi-prompts use :: separator for weighted combinations. Image prompts guide style from reference images.

## Commercial Use

Paid subscribers get full commercial usage rights for generated images.
